# Ars Magica 5E Definitive Edition · 中文可填写角色卡 (Web)

基于《魔法秘艺》（*Ars Magica Fifth Edition Definitive Edition*）官方 4 页版可填写角色卡（`Character Sheet [EN; color; fillable].pdf`）与《Ars Magica 合集 · 术语对照总表》（涵盖《血脉 True Lineages》《秘教 Mystery Cults》《同修 Societates》《罗马 Tribunals of Hermes: Rome》及五版核心规则）制作的纯静态网页版中文角色卡，可直接部署至 **GitHub Pages** 或在本地浏览器双击 `index.html` 离线使用。

## 功能特性

- **1:1 复刻官方 4 页角色卡结构与羊皮纸古籍视觉**：
  - **第 1 页**：角色/玩家/传奇、学派/年龄/体型/决意、衰朽与衰老影响、扭曲与扭曲影响、出身背景资料、八大属性（智力/感知/力量/耐力/仪态/沟通/灵巧/机敏）、优势与劣势、30 行能力列表。
  - **第 2 页**：人格特质、声望、战斗与穿戴护甲/吸收/护甲负重、六档疲劳等级（清爽/乏力/疲惫/力竭/眩晕/昏迷）、五档伤势与区间追踪、6 行武器公式计算表、18 格装备栏。
  - **第 3 页**：赫尔墨斯学派信息（学派/结社/法师徽记/宗庭/首席/尊长/学徒期结社）、魔法秘艺（五技法：创生/全视/万变/湮灭/掌控；十型式：动物/水/风/肉身/植物/火/意象/心灵/地/原初）、基础施法总值（范式/仪式/即兴公式、疾速施法速度、判定效果、基础瞄准、专注、魔法抗性）、工坊（基础工坊总值）、长寿仪式与暮光之痕、源质（以“卒”为单位）、魔宠（属性、战斗数值、铜线/银索/金绳、纽带特质与能力）。
  - **第 4 页**：12 栏完整法术记录卡（法术名、型式、技法、等级、加值、范围、持续时间、目标、经验、精通、备注）。
- **公式自动计算（可随时开关）**：
  - 根据体型（`Size`）自动推算轻伤、中伤、重伤、休克与死亡的伤害区间。
  - 选择学派（`House`）时自动同步第 1 页与第 3 页，并自动填充该学派对应的默认宗庭（`Domus Magna`）与首席（`Primus`）。
  - 自动从第 1 页能力栏提取 `精密`、`察觉`、`专注`、`绛咒`、`魔法理论` 等级，结合八大属性实时计算第 3 页的**疾速施法速度**、**判定效果**、**基础瞄准**、**专注**、**魔法抗性**与**基础工坊总值**。
  - 内置可展开的 **5×10 技法×型式 施法总值速查矩阵**（含范式总值与无疲劳即兴值）。
  - 自动计算第 2 页武器栏的先攻（`INIT`）、攻击（`ATK`）、防御（`DFN`）、伤害（`DAM`），以及第 4 页各法术的施法加值（`Bonus`）。
- **内置《术语对照总表》自动补全与速查抽屉**：
  - 学派、能力、优势/劣势、技法、型式、法术、范围/持续时间/目标输入框均接入中文术语下拉联想（`datalist`）。
  - 点击顶部工具栏 **「📖 术语对照表」** 即可随时按分类或中英文关键词检索对照词条。
- **中英双语 / 纯中文一键切换**：
  - 支持在「中文 + 英文副标」与「纯中文」显示模式间切换。
- **多角色本地存档 + JSON 导入导出 + A4 打印适配**：
  - 所有修改实时自动保存至浏览器 `localStorage`，支持创建并切换多个角色槽位。
  - 支持导出 `.json` 备份文件或从 `.json` 恢复。
  - 内置 `@media print` 4 页 A4 分页样式，点击 **「🖨 打印 / PDF」** 即可直接输出 4 页标准 PDF 角色卡。

## 本地使用与部署说明

### 1. 本地直接打开
直接用浏览器打开仓库根目录下的 `index.html`，或使用任意静态服务器预览：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

### 2. 部署至 GitHub Pages
1. 将本仓库推送至 GitHub。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment** 下选择 **Deploy from a branch**（选择 `main` 分支 `/ (root)` 目录）或使用内置的 **GitHub Actions** 工作流（`.github/workflows/deploy.yml`）。
