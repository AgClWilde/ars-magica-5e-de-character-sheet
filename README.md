# 魔法秘艺定本 网页版角色卡

角色保存在当前浏览器，建议定期导出 JSON 备份。

## 自动填写

- 学派：同步第 1、3 页；填写定本中的宗庭与首席。手动修改过的背景资料会保留。学派资料是书中默认背景，可随传奇调整。
- 法术：选定中文名、英文名或已收录别名后，填入技法、型式、等级、范围、持续时间、目标、固定前提及仪式标志。
- 通用等级法术保留空等级，请填写实际学习的版本。
- 武器：填写武器修正、能力、负重和射程，并勾选“携带”。只将实际携带的武器计入负重；同一武器的备选攻击方式不要重复勾选。护甲选名后填入防护值与负重。
- 优势、劣势分开补全。能力、秘艺、法术参数也有定本词条联想。

“自动填写”和“自动计算”分别开关。选择另一法术或装备会更新其规则参数。自订内容可以自由输入。

## 自动计算

- 体型决定伤势区间。多处伤口累加；疲劳勾选代表当前一档状态，伤疲惩罚与失能状态在“计算设置与当前状态”显示。
- 负重先按定本门槛换算负载，再减正力量得到负荷。先攻及施法扣除负荷。攻防栏不直接扣负荷；以其他携带物为主的负荷是否妨碍动作，由故事指引者裁定。
- 选定武器后，属性和指定战斗能力随第 1 页变化。闪避不产生攻击与伤害值；盾牌列出修正，需合并到所用武器。
- 护甲防护值或其他吸收修正有填写时，自动计算耐力＋防护＋其他修正。吸收不受伤势、疲劳惩罚。适用的型式加值可计入“其他吸收修正”。
- 法术施法加值分别取主技法／型式与相应前提的最低值，再加耐力、施法辉环及精通，扣除负荷；仪式再加自由七艺与哲学。结果不含骰值、伤势、疲劳或特殊优势的修正。
- 施法辉环与工坊辉环独立。输入的是依界域换算后的调整值：魔法为强度，妖精为强度的一半向下取整，天界为 −3 倍强度，下界为负强度。
- 疾速施法、确定效果型式、瞄准、专注及工坊基础小计随属性和能力更新。第 3 页绛咒小计为绛咒值的五倍；辅助区可按所选型式和当前辉环计算抗性，假定绛咒生效且未分享保护。
- 长寿仪式的工坊总值每满 5 点或不足 5 点，衰老掷骰修正为 −1；无超自然能力者勾选每 10 点。清空总值会清除旧结果。
- 秘艺矩阵显示常规施法加值及无疲劳即兴值，悬停可查看伤疲修正后的值。

自动计算开启时，派生属性取自第 1 页。关闭后可手动填写。空白数值按零处理；未知秘艺或前提不生成法术加值。

### 经验记录

默认沿用纸卡的经验进度，记录为将值提高一点而积累的经验；能力、秘艺及法术精通的值手填。“计算设置与当前状态”中可开启累计经验换算；这时能力和法术精通用五倍三角数门槛，秘艺用三角数门槛。开启前须把经验栏改为从零开始的累计投入。

清空累计经验会清除自动计算的值，之后可手填。经验学习修正应先反映在累计数中；直接提高能力值的优势不会自动应用。

## 存档与打印

沿用原有浏览器存档键和字段名，可直接载入旧角色及旧 JSON 文件。导入会创建独立角色，不覆盖当前角色。导出文件保留个人填写内容与自动填写来源标记。不同浏览器、不同网址或本地文件地址通常使用不同的存储空间，跨设备请导入导出。

默认提供 12 个法术块，可通过第 4 页底部的“新增法术块”按钮继续添加；新增内容随当前角色保存，并支持 JSON 导入导出。

默认角色卡的中文与双语均适配四页 A4，新增法术块会按需增加打印页。打印时选择 A4、默认缩放，并关闭浏览器页眉页脚。

## GitHub Pages 发布

上传项目文件时须保留 `.github/workflows/deploy.yml`，并包含 `rules.js`。在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，再将文件更新到 `main`；工作流也支持在 Actions 页面手动运行。

工作流使用官方 Pages artifact 发布方式，运行环境固定为 Ubuntu 24.04，动作采用 Node.js 24 版本。发布包包含页面所需的全部脚本、样式和署名说明；上传前会检查页面引用的本地资源是否齐全。配置或发布失败会直接报告失败。
