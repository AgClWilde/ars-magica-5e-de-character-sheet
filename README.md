# 魔法秘艺定本 网页版角色卡

在浏览器中填写角色卡，可自动补全规则资料、计算常用数值，也可以手动填写。支持中文和双语版式，以及 A4 打印。

**角色保存在当前浏览器中，请导出 JSON 文件备份。** 

## 开始填写

“自动填写”和“自动计算”可以分别开关：

- **自动填写**：选中已有条目后，补全相关规则资料。可以直接输入自定义内容。
- **自动计算**：根据第 1 页的属性、能力等资料，更新相关数值。

## 保存与备份

角色保存在当前浏览器的存储空间中。导出 JSON 可以备份角色，也可以把角色带到另一台设备上。导入时会创建一个独立角色，不会覆盖当前角色。旧角色存档和旧版 JSON 文件也可以继续载入。

## 经验记录

默认按纸质角色卡的方式填写：**经验栏记录升到下一级已经积累的经验，能力、秘艺及法术精通的值由你手填。**

如果希望根据经验自动换算数值，可以在“计算设置与当前状态”中开启“累计经验换算”。开启前，务必将经验栏改为该项**从零开始累计投入的全部经验**，不能继续填写当前一级的进度。

<details>
<summary>累计经验的换算方式</summary>

能力和法术精通采用五倍三角数门槛，秘艺采用三角数门槛。

学习经验的修正需要先计入累计经验。直接提高能力值的优势不会自动应用。

清空累计经验后，对应的自动计算值也会清除，之后可以手填。

</details>

## 自动计算说明

自动计算会处理常用数值，但仍有一些修正需要按实际情况判断。例如，法术栏中的施法加值不含骰值、伤势、疲劳及特殊优势的修正。

伤势、疲劳惩罚和失能状态可在“计算设置与当前状态”中查看。空白数值通常按零处理；无法识别的秘艺或前提不会生成法术加值。

<details>
<summary>伤势、疲劳、负重与战斗</summary>

- **伤势与疲劳**：体型决定伤势区间，多处伤口的惩罚累加。疲劳勾选表示当前所处的一档状态。
- **负重**：先按定本门槛把负重换算为负载，再减去正的力量值得到负荷。先攻和施法会扣除负荷，攻防栏不会直接扣除。
- **武器与盾牌**：选定武器后，相关属性和指定战斗能力随第 1 页更新。盾牌只列出修正，需要合并到所用武器。
- **吸收**：填写护甲防护值或其他吸收修正后，按“耐力＋防护＋其他修正”计算。适用的型式加值可以填入“其他吸收修正”。

</details>

<details>
<summary>施法、辉环与绛咒</summary>

**法术施法加值**分别取主技法与技法前提、主型式与型式前提中的最低值，再加耐力、施法辉环及精通，扣除负荷。仪式法术另加自由七艺与哲学。结果不含骰值、伤势、疲劳或特殊优势的修正。

**施法辉环与工坊辉环分开填写。** 输入的是依界域换算后的调整值：

| 界域 | 填写数值 |
| --- | --- |
| 魔法 | 辉环强度 |
| 妖精 | 辉环强度的一半，向下取整 |
| 天界 | 辉环强度的 −3 倍 |
| 下界 | 辉环强度的负值 |

**绛咒与抗性**：第 3 页的绛咒小计为绛咒值的五倍。辅助区可根据所选型式和当前辉环计算抗性，计算时假定绛咒已生效，且没有向他人分享保护。

**其他小计**：疾速施法、确定效果型式、瞄准、专注及工坊基础小计会随属性和能力更新。秘艺矩阵显示常规施法加值与无疲劳即兴值，悬停可查看计入伤势、疲劳修正后的数值。

</details>

<details>
<summary>长寿仪式</summary>

长寿仪式的工坊总值每 5 点提供 −1 的衰老掷骰修正，不足 5 点的部分也算一档。无超自然能力者请勾选每 10 点换算的选项。

清空工坊总值时，之前算出的修正也会清除。

</details>
